| 决策点 | 结论 |

## 1. 世界观与「域外来客」

- **域外来客是横跨三界的阵营（Faction）**，不是第四世界。`World` 枚举（Shinwa/Aether/Ironveil）**不动**，给 5 人打 `Faction = 域外`，Lore 统一为「裂隙坠入」叙事（衔接现有钢铁侠 Lore 的跨维度裂隙伏笔）。
- 命名用「称号 + 名」结构，与山海经本体的 2 字古兽神名（烛龙/刑天/蚩尤/饕餮）形成两套命名体系。

|---|---|---|---|---|

### 技术约束（红线）

- `CharacterId`（拼音，立绘文件名 `char_<rarity>_<pinyin>` 依赖它）**保持不变**，只改 `DisplayName`，避免破坏存档与资源引用。
- `World` 枚举不动；`Faction` 字段已有，仅改值。
- 序列化结构不动（`@SerialName` 对齐 data.json 的 PascalCase 键）。

## 2. 立绘规格与重绘

### 规格统一（根因：2:3 与 3:4 混用导致裁切不一致）

| 稀有度 | 数量 | 目标分辨率 | 比例 |
|---|---|---|---|
| R | 7 | 1024×1536 | 2:3 |
| SR | 7 | 1024×1536 | 2:3 |
| SSR | 7 | 1280×1920 | 2:3 |
| UR | 10 | 1280×1920 | 2:3 |

- 全部透明底（PNG/WebP），画心内自由裁切。
- 修复倒挂：现 UR 864×1152 低于 SSR 1280×1920，统一后消除。
- UR 与 SSR 同分辨率，UR 靠卡面光效 / 金箔装裱体现地位。

### 风格约束

- 水墨金箔（水墨 / 朱砂 / 青瓷配色），禁霓虹 / gacha 风。
- 武器按角色 lore 定制、不复用通用几何、不叠覆立绘。
- 两套视觉族：山海经本体（26）= 水墨工笔 + 神兽威严；域外来客（5）= 机巧 / 秘术异质感（青铜 / 鎏金纹理，非赛博霓虹）。
- 重绘复用 `docs/superpowers/art-direction/portraits-v2/` 管线（生成 → 去背 → 超分 → QC）。

## 3. 卡牌展示（装裱册页）

### 卡面结构（通用 CharacterCard + 抽卡结果卡共用）

- 外圈**装裱边**承载稀有度材质：UR 金箔 / SSR 朱漆绫 / SR 青瓷锦 / R 素绢。
- 内圈**画心**：深墨底（BgDeepest 0x0A0A0F），放立绘。
- 底部**名字铭牌**：称号 + 名。
- 右上角**元素徽章**。
- 右下角**朱砂落印**（稀有度角标，升级为落印动画）。

### 稀有度材质映射

| 稀有度 | 装裱材质 | 主色 | 语义 |
|---|---|---|---|
| R | 素绢 | 素白 D8D0C0 | 质朴 |
| SR | 青瓷锦 | 石青 7EBAB1 | 清雅 |
| SSR | 朱漆绫 | 朱砂 C85050 | 尊贵 |
| UR | 金箔 | 金箔 F0C864 | 至臻 |

### 抽卡演出水墨化（替换 CyberCards.kt）

- 单抽：册页展开 → 画心墨迹晕染显影 → 朱砂落印。
- 十连：十张册页阵列铺开 → 逐张翻显 → 按稀有度分批落印。
- 光效去品红 / 故障 / 数字雨，改为金箔光；稀有度靠装裱材质 + 落印深浅 + 光晕强度（UR 最强）。

### 卡背重设计

- 素绢 / 玄色底 + 中央水墨团纹（祥云 / 回纹 / 神兽剪影）+ 金箔描边，不分稀有度。

### 图鉴 / 编队卡

- 装裱边收窄（约 4dp），同一语言缩放；抽卡结果大卡用宽装裱边。

## 4. 故事重写与排版

### 内容三段式（31 角色全量改写）

`Story` 字段用 `\n\n` 分段，不新增字段、不动序列化结构：

1. **本源** —— 山海经本体写古籍原型与神位；域外来客写异界文明与坠入裂隙。
2. **执念** —— 驱动角色的核心动机。
3. **羁绊** —— 在三界中的位置与人物关系。

`Lore` 保持一句话人设，统一口径。

### 排版升级（StoryPanel）

- 分段小标（本源 / 执念 / 羁绊）+ 正文。
- 首段首字下沉（drop cap）。
- 朱砂分隔符。
- 长文折叠「更多」。

## 5. 实施顺序（硬约束）

1. **P0 故事重写**（纯文本，无依赖，先行）—— 31 角色 Lore + Story 三段式。
2. **P1 数据接入**（DisplayName 改 5 个 IP 角色 + Faction 域外）—— 与故事同步。
3. **P2 卡牌视觉**（装裱册页落地：CharacterCard 重构 + CyberCards 水墨化 + 卡背）—— 依赖 P1 的命名与 Faction。
4. **P3 立绘重绘**（31 张 AI 出图，成本最高，独立可并行）—— 依赖 P1 命名定稿，产出透明底 2:3。
5. **P4 排版升级**（StoryPanel 结构化）—— 依赖 P0 分段约定。

## 6. 风险与未决

- 立绘重绘覆盖原图**不可逆**，需单独确认后启动；重绘 31 张成本远高于其余各项。
- `CharacterId` 保留旧拼音（如钢铁侠仍 `gangtiexia`），后续若要彻底改名需迁移存档，不在本轮范围。
- 充值合规、其他 P2+ 设计缺口与本轮无关，不触碰。
