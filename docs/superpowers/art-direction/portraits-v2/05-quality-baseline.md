## 6. 关键风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| **AI 生图无法精确控制"识别锚点"** | 狻猊再生成还是猪头 | 多 seed + ImageMagick 面部特征检测 + 人工二次确认 |
| **无身体角色（饕餮）构图挑战** | 难以表现"有首无身" | 先打 10+ 个小稿测试，选最佳 |
| **机械角色（蚩尤/刑天/穷奇）四臂/无头解剖** | 解剖不准确易被识别为"故障" | 提前画小稿（512×768）测试解剖 |
| **透明背景细节丢失** | 头发丝/羽毛/能量流失真感 | 后期人工精修羽化（≤2px）+ 边缘检查 |
| **版权风险（桔梗/刻晴联动 IP）** | 风格"过像"侵权 | 保留核心识别元素（发型/服饰），加差异化设计 |
| **AI 生成肤色与种族偏见** | 烛龙/金乌应是东方神话形象 | 强化 Prompt 中"East Asian features, Chinese mythology" |
| **新元素体系（Light/Wood）无现成参考** | 配色不统一 | 严格按 `00-master-spec.md` §4.3 元素色板执行 |
