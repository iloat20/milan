# Milan UI 重新设计规格

> 日期：2026-07-29 · 状态：已批准

对首页、抽卡、检视三个核心界面做视觉重设计，统一为"宇宙星穹"风格。

## 视觉风格：宇宙星穹

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景深 | `#0d0221` | 最深层背景 |
| 背景浅 | `#1a0533` | 渐变结束色 |
| 主色 | `#7c4dff` | 星紫，按钮/边框/光晕 |
| 主色浅 | `#b388ff` | 浅星紫，次级光晕 |
| 点缀金 | `#ffd75a` | 星尘货币、高稀有度 |
| 文字主 | `#ffffff` | 标题 |
| 文字次 | `#b8b8d0` | 描述 |
| 文字弱 | `#7a7a99` | 辅助信息 |

**质感**：深紫径向渐变光晕、发光边框（`SetShadowLayer`）、浮动粒子、呼吸式脉动动画。

## 1. 首页 — 聚焦式英雄区

### 布局
```
┌─────────────────────────────┐
│  MILAN          [星尘 999999] │  ← 顶部栏：logo + 货币
│  次元裂缝                     │
│                               │
│         ╭───────╮             │
│        ( 召唤光圈 )  ← 旋转光晕+粒子   │
│         ╰───────╯             │
│                               │
│  ┌─────┐  ┌─────┐  ┌─────┐   │
│  │ 抽卡 │  │ 角色 │  │ 图鉴 │   │  ← 三入口放射排列
│  └─────┘  └─────┘  └─────┘   │
│                               │
│       已拥有 5 个角色          │  ← 底部数据
└─────────────────────────────┘
```

### 元素
- **Logo**：`MILAN` 星紫渐变 + 发光阴影
- **召唤光圈**：`ParticleView` 的 glow 模式，持续旋转脉动
- **三入口**：圆形图标按钮，hover 态放大 + 光晕
- **底部数据**：星尘（金色）+ 角色数

### 动画
- 光圈持续呼吸脉动（scale 1.0 ↔ 1.05）
- 背景浮动粒子缓慢上升
- 入口按钮点击时向外扩散光环

## 2. 抽卡 — 裂缝召唤

### 布局
```
┌─────────────────────────────┐
│ ‹ 返回    次元裂缝 · 常驻     │
│            [保底: 47/90]      │
│                               │
│  ┌─────────────────────────┐ │
│  │  UR 10% · SSR 20%       │ │  ← 卡池信息
│  │  SR 30% · R 40%         │ │
│  └─────────────────────────┘ │
│                               │
│         ╭───────╮             │
│        ( 召唤光圈 )  ← 点击触发裂缝   │
│         ╰───────╯             │
│                               │
│  ┌──────────┐  ┌──────────┐   │
│  │  单 抽    │  │  十 连    │   │  ← 按钮
│  │  160 星尘 │  │ 1600 星尘 │   │
│  └──────────┘  └──────────┘   │
└─────────────────────────────┘
```

### 召唤动画序列
1. 点击按钮 → 光圈加速旋转 + 亮度提升
2. 中心闪光（全屏白色 flash，alpha 0→180→0，0.3s）
3. 粒子爆发（spark 模式，30 粒子径向飞散）
4. 结果卡牌从中心弹出（scale 0→1，staggered 0.05s/张）

### 结果展示
- 十连：2×5 网格，卡牌背面朝上
- 高稀有度（SSR/UR）卡牌带发光边框 + 稀有度色光晕
- 点击卡牌翻转 → 显示角色立绘 + 名字
- 已拥有角色显示"重复→碎片"标记

### 货币反馈
- 抽卡后星尘数字滚动动画
- 不足时按钮置灰 + 红色提示

## 3. 检视 — 展示厅

### 布局
```
┌─────────────────────────────┐
│ ‹ 返回          [角色名]     │
│                               │
│  ┌─────────────────────────┐ │
│  │                         │ │
│  │    ╭───────────────╮    │ │
│  │   (   角色立绘区域   )   │ │  ← 全身立绘 + 光晕
│  │    ╰───────────────╯    │ │
│  │                         │ │
│  └─────────────────────────┘ │
│                               │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐ │
│  │旋转│ │缩放│ │技能│ │信息│ │  ← 操作栏
│  └────┘ └────┘ └────┘ └────┘ │
│                               │
│  [立绘] [天赋] [故事] [羁绊]  │  ← 标签页
└─────────────────────────────┘
```

### 交互
- **单指拖动**：角色旋转（yaw）
- **双指捏合**：缩放
- **点击身体部位**：高亮 + 部位名称提示
- **技能按钮**：触发 burst 动画（全屏闪光 + 粒子）
- **标签页**：切换立绘/天赋/故事/羁绊内容

### 动画
- 角色待机：呼吸式上下浮动（translateY ±4px，2s 周期）
- 光晕：持续脉动
- 切换标签：内容淡入 + 上移

---

## 通用组件

### CosmicBackground
全屏深紫渐变 + 缓慢旋转的星光粒子，作为三个界面的统一背景。

### GlowButton
带发光反馈的按钮：常态边框光晕 → 按下时光晕增强 + 缩放 0.95。

### ResultCard
结果展示卡牌：背面（星空纹理）→ 翻转 → 正面（立绘+名字+稀有度边框）。
