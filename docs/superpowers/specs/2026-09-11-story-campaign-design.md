## 1. 叙事总纲

### 1.1 玩家身份：织环者（Ring-Weaver）

- 千年前「大崩解」撕碎原初之环；环的**回响**未死，在裂隙纪元重新凝聚成「你」。
- 你没有固定神位/机甲/星图——你是**能与三界英灵共鸣、把碎片重新拼回整体**的人。
- 抽卡 = **召灵**：裂隙送来的英灵应你的回响而来；养成 = **共鸣加深**；爬塔 = **镇压裂隙扩张**。
- 对外一句话（与 narrative-ui §1.1 对齐）：

> **裂隙撕开三界，你是织环者——在碎片间召唤英灵，把破碎的原初之环重新拼回世界。**

### 1.2 三幕结构

```
第一幕 · 三残片（ch01–03）   各自世界危机 → 学会召灵与组队
第二幕 · 裂隙联军（ch04–06） 三界被迫结盟 + 域外来客坠入
第三幕 · 终焉与重织（ch07–09）虚无降临的真相 → 选择世界结局
```

| 幕 | 章 | 标题 | 主场 | 门面视角 | 核心冲突钩子 |
|----|----|------|------|----------|--------------|
| I | 1 | 永昼之焰 | Shinwa | 烛龙 / 金乌 | 烛龙睁眼七日压裂隙，河干草焦 |
| I | 2 | 星环低语 | Aether | 女娲 / 商羊 / 曜 | 议会研究裂隙，反而唤醒虚无 |
| I | 3 | 钢心未冷 | Ironveil | 刑天 / 蚩尤 | 兵主是进化终点还是被奴役武器 |
| II | 4 | 三界会盟 | 跨界 | 烛龙 + 曜 + 刑天 | 神明回归 vs 人定胜天当面撕 |
| II | 5 | 域外坠星 | 跨界 | 公输玄 / 苍霆 / 玄微 | 异界来客带技术，也带更大的裂隙 |

| III | 9 | 重织之环 | 原初之环遗址 | 全员轮转 | 环能否重织——三种收束 |

### 1.3 四条贯穿冲突线（必须在对话里可感知）

1. **永昼 vs 归无**（烛龙 ↔ 虚无）：秩序节律与宇宙还债。
2. **人定胜天 vs 神明回归**（曜/刻晴线 ↔ 烛龙）：被研究、被超越，还是重新敬畏。
3. **钢与血**（刑天 ↔ 蚩尤 ↔ 铁帷高层）：护民之盾 vs 毁灭之矛 vs 「武器是否为人」。
4. **创造 vs 湮灭**（女娲 ↔ 虚无；青璃旁证）：泥塑存在 vs 抹消存在。

## 4. 裂隙兽谱（敌人内容规格）

## 5. 章节详设

> 每章固定 5 关，节奏：**对白建立 → 战 → 对白/选择 → 战 → 终章收束**。
> 对白每关 4–8 行；每行 ≤ 40 字（打字机预算）。
> 情绪枚举沿用：`normal / happy / angry / sad / surprised / serious / tease`。

## 6. 系统与数据约束（红线）

1. **不改 `@SerialName` / 存档结构**；ch08 分支首期不落结局字段。
2. **不改 `StrikeEvent` / 战斗计算**；`enemyIds` 可换字符串，战力仍走荐等推演。
3. **内容定义仍在 `StoryService.STORY_CHAPTERS` 代码内**（与现状一致）；若未来要 data.json 热更，另立序列化模型提案。
4. **说话者必须是真实 `CharacterId` 或 `narrator`**；DialogueScreen 经 `characterOf` 查名，错 ID 会落到占位。
5. **好感**：`StoryChoice.affinityBonus > 0` 时 UI 已接 `grantAffinity`；**未拥有该角色时**服务层可能 Rejected——文案设计不依赖「必加成功」，失败静默（现网行为）。
6. **文案长度**：对白 ≤ 40 字/行；选项 ≤ 16 字；章节副标题 ≤ 12 字。
7. **新手引导**（narrative-ui §6）复用 **ch01_s1 精简 3–4 行**，不另写大段。
