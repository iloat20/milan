# Milan UI 重新设计 — 原神风格

> **日期**: 2026-07-30 | **状态**: 设计定稿 → 实现
> **目标**: 将所有界面升级为原神/星铁风格的抽卡游戏UI

---

## 1. 设计风格定义

### 视觉关键词
- **精致3D感**：角色立绘占据视觉中心，有呼吸感和空间感
- **华丽光效**：稀有度光晕 + 粒子特效 + 动态闪光
- **卡牌突出**：每个界面都以角色立绘为核心
- **流畅动效**：呼吸旋转、粒子流动、光效脉动

### 稀有度特效规范
| 稀有度 | 主色调 | 光晕 | 粒子 | 特效强度 |
|--------|--------|------|------|----------|
| UR | 金色 #FFD700 | 强光晕 | 金色上升粒子 | 全屏闪光 |
| SSR | 紫色 #D070FF | 中光晕 | 紫色粒子 | 强光 |
| SR | 蓝色 #3AA0FF | 弱光晕 | 蓝色粒子 | 中等光效 |
| R | 白色 #FFFFFF | 微光 | 无 | 微弱 |

## 2. 检视界面（最高优先级）

### 布局
```
┌─────────────────────────────────┐
│  ← 返回     角色名    [UR]      │  顶部信息条(透明背景)
│─────────────────────────────────│
│                                 │
│         ╭───────────╮           │
│         │           │           │
│         │  角色立绘  │  ← 60%屏幕
│         │  可旋转   │   ← 稀有度光晕
│         │  粒子环绕  │   ← 缓缓飘动
│         ╰───────────╯           │
│                                 │
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐│
│  │ 旋转 │ │ 缩放 │ │ 技能 │ │ 信息 ││  底部操作栏
```

### 视觉要求
- 立绘占屏幕60%，背景虚化突出主体
- 稀有度光晕持续脉动（呼吸效果）
- 粒子从角色周围缓缓上升
- 边缘有能量流动效果

### 交互
- 左右拖拽：360°旋转角色
- 双指缩放：放大查看细节
- 点击「技能」：释放特效（闪光 + 粒子爆发）
- 点击「信息」：弹出角色详情对话框

### 实现要点
1. 重写 InspectionActivity 布局
2. PortraitView 增加光晕脉动动画
3. 增加粒子系统（环绕角色）

## 4. 抽卡演出

### 流程
1. **准备状态**：裂缝旋转 + 能量聚集
2. **召唤动画**：白屏闪光 → 角色从光中浮现
3. **结果展示**：角色立绘 + 稀有度粒子

### 特效层级
| 阶段 | 特效 | 时长 |
|------|------|------|
| 裂缝放大 | 能量聚集 + 旋转 | 0.5s |
| 闪光 | 全屏白屏 | 0.2s |
| 角色登场 | 从光中浮现 + 放大 | 0.5s |
| 粒子消散 | 稀有度粒子环绕 | 持续 |

### 实现要点
1. 增强 GachaActivity 的裂缝演出
2. 闪光后显示角色立绘（不只是卡片）
3. 稀有度光效爆发
