## 1. 设计系统

### 1.1 配色方案 —— "Obsidian & Gold"（黑曜石 + 鎏金 + 霓虹）

在现有宇宙暗色基础上收敛为三层结构：**深色底 → 半透明玻璃面板 → 高对比金色/霓虹点缀**。

#### 基础层（背景）

| Token | 色值 | 用途 |
|---|---|---|
| `BgDeepest` | `#07070F` | 全局最底层，替代现 `#0d0d1a` |
| `BgNebula` | `#0D0221 → #1A0B3D` 径向渐变 | CosmicBackground 星云层 |
| `BgVignette` | `#000000` α40% 四角压暗 | 所有页面顶层暗角，聚焦中心 |

#### 面板层（玻璃拟态 Glassmorphism）

| Token | 色值 | 用途 |
|---|---|---|
| `PanelGlass` | `#1A1A2E` α78% | 通用卡片/面板底色 |
| `PanelGlassLight` | `#252542` α65% | 二级嵌套面板 |
| `PanelBorder` | `#FFFFFF` α12% 1dp 描边 | 玻璃面板高光边 |
| `PanelBorderGold` | `#FFD75A` α45% 1.5dp | 强调面板（当期UP、选中态） |

#### 点缀层（金色 + 霓虹，高对比）

| Token | 色值 | 用途 |
|---|---|---|
| `GoldPrimary` | `#FFD75A` | 主金色：主按钮、货币、标题饰线 |
| `GoldDeep` | `#C9962E` | 金色渐变收尾、按钮底边 |
| `GoldGlow` | `#FFE9A8` α60% | 金色元素外发光 |
| `NeonCyan` | `#00E5FF` | 霓虹青：次级操作、信息高亮、扫光 |
| `NeonMagenta` | `#FF3DAE` | 霓虹粉：限定/活动角标 |
| `AccentRed` | `#E94560` | 战斗/危险操作（保留现值） |

#### 稀有度（沿用 `AppTheme.RarityColor` 唯一来源，微调提亮）

| 稀有度 | 主色 | 卡框渐变 | 特效 |
|---|---|---|---|
| R | `#9BA3AF` | 银灰哑光 | 无 |
| SR | `#3AA0FF` | 蓝→冰青 `#7FDBFF` | 静态微光边 |
| SSR | `#D070FF` | 紫→品红 `#FF6BD6` | PulseView 呼吸光晕 |
| UR | `#FF6B00` | 橙→鎏金 `#FFD75A` | 光晕 + ShineView 流光 + 边缘粒子 |

#### 功能色

`Success #35D07F` ｜ `Warning #FFB020` ｜ `Danger #FF4D5E` ｜ `TextPrimary #F5F0FF` ｜ `TextSecondary #9C9CB8` ｜ `TextDisabled #5A5A72`

### 1.2 字体与层级

| 层级 | 规格 | 用法 |
|---|---|---|
| Display | 28sp / Bold / 字距 +2% / 金色渐变填充 | 页面大标题、抽卡结果稀有度 |
| Title | 20sp / Bold / `TextPrimary` | 面板标题、角色名 |
| Body | 15sp / Regular / `TextPrimary` | 正文、描述 |
| Caption | 12sp / Medium / `TextSecondary` | 属性标签、次要信息 |
| Numeric | 17sp / Bold / 等宽数字 / `GoldPrimary` | 货币、战力、伤害数字 |

标题统一加"饰线"元素：文字左右各一条 `GoldPrimary` α60% 的 1dp 渐隐横线 + 中心菱形◆，营造卡牌游戏铭牌感。

### 1.3 间距 / 圆角 / 立体感

- 间距节奏：4 / 8 / 12 / 16 / 24 dp（页面边距 16dp，卡片间距 12dp）。
- 圆角：小组件 8dp，卡片 14dp，弹窗 20dp，全面板 24dp。
- **立体感三件套**（所有可点击元素必备）：
  1. 顶部内高光：`#FFFFFF` α18% → 透明，覆盖上半 40%；
  2. 底部投影：`#000000` α50%，offsetY 3dp，blur 8dp；
  3. 描边：外圈 1dp 深色 + 内圈 1dp 亮色（双描边浮雕效果）。

## 2. 核心组件规范

### 2.1 按钮

| 类型 | 视觉 | 用途 |
|---|---|---|
| **金色主按钮** | `GoldPrimary→GoldDeep` 垂直渐变，斜切角(左上/右下 6dp 切角) 造型，双描边，常驻 ShineView 每 4s 扫光一次，文字深色 `#3A2800` | 召唤、出战、购买确认 |
| **霓虹次按钮** | 透明底 + `NeonCyan` 1.5dp 描边 + 内发光 α20%，按压时填充 α15% | 详情、筛选、取消 |
| **危险按钮** | `AccentRed` 渐变，同主按钮造型 | 分解、放弃战斗 |
| **图标圆钮** | 44dp 圆形玻璃面板 + 金色图标 | 返回、设置、关闭 |

按压反馈统一：缩放 0.96 + 亮度 +10%，80ms 进 / 120ms 出（沿用 GlowButton 机制）。

### 2.2 卡牌（角色卡）

三种规格，统一结构 = 稀有度渐变边框(2.5dp) → 立绘 → 底部渐黑信息条 → 角标：

- **S 卡** 3:4（图鉴/卡组网格）：立绘 + 名字 + 元素角标 + 星级；
- **M 卡** 3:4.2（抽卡结果/列表）：增加等级、战力，SSR/UR 挂 PulseView；
- **L 卡** 16:10 横幅（主页 Featured、当期UP）：立绘右置 + 左侧信息区 + 对角线金色饰带。

卡背设计：`BgNebula` 底 + 中央金线几何法阵纹章 + 四角金色包角，用于翻转动画背面。

### 2.3 弹窗

- 结构：全屏 `#000` α65% 遮罩（带 8dp 高斯模糊感的双层遮罩近似）→ 中央玻璃面板(20dp 圆角、`PanelBorderGold` 描边) → 顶部金色饰线标题 → 内容 → 底部按钮双列。
- 顶部中央外凸一个菱形金色徽记（图标随弹窗类型变化）。
- 入场：缩放 0.85→1 + 淡入，OvershootInterpolator(1.2)，240ms；遮罩独立淡入 160ms。

### 2.4 导航栏（全局统一，替代现三键栏）

- **竖屏**：底部 64dp 玻璃面板导航，5 项：主页 / 抽卡 / 卡组 / 商店 / 图鉴。选中项：图标上浮 4dp + 金色填充 + 底部 3dp 金色光条 + 微粒子。
- **横屏**：左侧 72dp 竖排导航栏，同样式垂直排列。
- 顶部资源条（所有一级页共用）：左侧玩家头像+等级环，右侧金币/钻石胶囊（玻璃底 + 金色数字 + "+"号霓虹青）。

## 3. 各页面视觉设计说明

### 3.1 主页（HomeActivity 重设计）

- **背景**：BgNebula 星云 + CosmicBackground 星点 + 前景 2~3 片大型半透明世界剪影（WorldDecoration），三层视差（陀螺仪/滑动偏移 0.3x/0.6x/1x）。
- **顶部**：资源条（见 2.4）。
- **中央视觉主体**：当期 UP 角色全身立绘居右站立（高约屏高 55%），脚下椭圆光圈 + 环绕 Stardust 粒子；左侧纵向排布：活动轮播卡（L 卡横幅，自动轮播 5s，金色指示点）、限时活动倒计时胶囊（NeonMagenta 描边）。
- **右侧浮动入口列**：46dp 图标圆钮竖排 —— 邮件 / 任务 / 签到，带红点（`AccentRed` 圆点 + 呼吸）。
- **底部**：主导航栏之上放一颗大号金色主按钮「出 战」（居中偏右，双倍高度 60dp，常驻扫光），点击进战斗准备。
- **氛围**：每 20s 一颗流星划过背景；立绘待机呼吸（scale 1↔1.008，3s 循环）。

### 3.2 抽卡页（GachaActivity 重设计）

- **背景**：加深星云 + 中央巨型半透明法阵（缓慢自转 60s/圈，金线描边）。
- **顶部**：卡池切换横向 Tab（玻璃胶囊，选中金色填充）+ 剩余保底计数（霓虹青数字）。
- **中央**：当期 UP 角色立绘 + UR 概率 UP 铭牌（金框 + NeonMagenta「限定」角标）。
- **底部操作区**：玻璃面板托底，左「单次召唤 ×1」霓虹次按钮，右「十连召唤 ×10」金色主按钮（更大，带扫光 + 底部小字"必得 SR 以上"）；面板左上角"概率详情"文字链（霓虹青下划线）。
- **演出升级**（保留现有多段演出骨架，见 5.3）：召唤阵聚能 → 稀有度色域全屏闪 → **卡背翻转揭示**（新增）→ 立绘爆发。
- **结果页**：十连 5×2 网格错峰入场；SSR/UR 卡自动翻转揭示并触发粒子爆发，其余卡直接亮面；底部「再次召唤」金色按钮 + 「确认」次按钮。新出货角标「NEW」用 NeonMagenta 斜带。

### 3.3 战斗页（BattleActivity — 新页面）

- **布局（横屏为主，见 4.2）**：
  - 上：敌方单位横排（3~5 个），头顶血条（红渐变 + 白色削减残影）+ 增益/减益图标行；
  - 中：战场区，队伍单位站桩 + 技能特效层（ParticleView 全屏覆盖）；
  - 下：**手牌区** —— 5 张 S 卡呈扇形微弧排列（各卡 rotation -6°~+6°，中央凸起 8dp），可拖拽出牌；
  - 左下：费用水晶条（菱形水晶 ×10，已用变暗，回费时金色波光依次点亮）；
  - 右下：「结束回合」金色圆形大按钮（56dp，可用时呼吸金光，不可用灰置）；
  - 顶部中央：回合数铭牌 + 敌方行动预告图标；左上：暂停图标圆钮。
- **出牌交互**：拖起卡牌 → 卡牌放大 1.15 + 其余手牌让位收拢 → 战场出现绿色可放置光圈/目标单位红色锁定框 → 松手命中：卡牌化为光粒子飞向目标 + 技能粒子爆发 + 伤害数字弹跳（暴击为金色大号 + 屏幕微震 60ms）。
- **配色纪律**：战场信息用高对比（我方血条 `Success`、敌方 `AccentRed`），特效再华丽也不遮挡血条/费用层。

### 3.4 卡组编辑页（DeckBuilderActivity — 新页面）

- **双栏结构**（竖屏上下 4:6，横屏左右 4:6）：
  - **卡组区**：顶部卡组名（可编辑，金色饰线）+ 战力总值（Numeric 金色大字）+ 元素占比环形图；卡组槽位 2×4（或横屏 1×8）玻璃凹槽，空槽显示"+"虚线框（呼吸 α 闪烁），已放入显示 S 卡。
  - **卡池区**：筛选栏（元素/稀有度/战力排序，霓虹胶囊多选）+ S 卡网格（竖屏 4 列 / 横屏 6 列），已入组的卡片加金色勾角标并压暗 30%。
- **交互**：长按卡池卡 → 浮起（scale 1.1 + 投影加深）拖入槽位，槽位吸附时金圈高亮，落位金色涟漪；点按 = 快速添加/移除（卡片飞行动画到槽位）。冲突（同名卡）时槽位抖动 + 红闪。
- **底部**：「保存卡组」金色主按钮 + 「一键配卡」霓虹次按钮。

### 3.5 商店页（ShopActivity — 新页面）

- **顶部**：资源条 + 商店分区 Tab（礼包 / 钻石 / 碎片兑换 / 每日特惠），Tab 下金色光条滑动指示。
- **每日特惠区**：横向滑动 L 卡横幅，"限时"倒计时翻牌数字（NeonMagenta），折扣标签为撕角红色饰带（-30%）。
- **商品卡**：竖屏 2 列网格；玻璃面板 + 商品图居中悬浮（底部椭圆投影）+ 名称 + 价格胶囊（货币图标+金色数字）。稀有礼包用 `PanelBorderGold` 描边 + 常驻微流光。
- **购买流程**：点击 → 确认弹窗（2.3 规范，展示内容物列表）→ 成功后全屏"获得展示"：黑幕 + 物品从中心光爆中弹出（UR 级触发彩带粒子）。
- **已售罄**：整卡去饱和 + 对角"已售罄"印章。

### 3.6 设置页（SettingsActivity — 新页面）

- 玻璃面板分组列表：账号 / 音频（音乐、音效滑杆）/ 画质（粒子密度：低中高分段选择器）/ 通知 / 语言 / 关于。
- **滑杆**：轨道玻璃凹槽，已填充段金色渐变，滑块为发光菱形水晶。
- **开关**：胶囊型，开=金色填充+滑块发光，关=灰玻璃。
- **分段选择器**：霓虹青描边胶囊组，选中项填充。
- 顶部玩家卡片：头像（稀有度色环）+ 昵称 + UID（可复制，点击霓虹青闪烁提示）。
- 底部：版本号 Caption + 「退出登录」危险按钮（幽灵样式：红描边透明底）。

### 3.7 角色列表页（CharacterListActivity 重设计）

- 顶部筛选/排序栏（同 3.4 卡池筛选样式）+ 拥有数量统计（金色 12/48）。
- M 卡网格竖屏 3 列；卡片入场瀑布流错峰淡入上移（每张延迟 40ms）。
- 长按卡片 → 弹出快捷预览浮层（大立绘 + 关键属性），松手关闭。

### 3.8 角色详情页（CharacterDetailActivity 重设计）

- **沉浸式**：全屏立绘为底（顶部溢出裁切），元素主题色（ElementTheme）渐变光从立绘背后透出；信息面板为底部 55% 高度的可上滑玻璃抽屉（上滑展开至 85%）。
- 抽屉内 Tab：属性 / 技能 / 天赋 / 羁绊；技能图标为六边形金框，点击展开描述（高度动画 200ms）。
- 右上角「360°检视」图标圆钮 → 转场进 InspectionActivity（共享元素：立绘缩放过渡）。
- 星级升星槽：已点亮金星带光晕，未点亮空心灰星。

### 3.9 图鉴页（CollectionActivity 重设计）

- 顶部收集进度条：金色渐变填充 + 百分比 + 里程碑节点（达成节点亮金色菱形）。
- S 卡网格：未拥有卡显示为**剪影卡**（立绘纯黑剪影 + 稀有度描边 α30% + 中央"?"）；新获得未查看的卡带 NeonMagenta 角标。
- 按世界（WorldTheme 三世界）分区，区头用对应世界主色饰带 + 世界纹章。

### 3.10 360°检视页（InspectionActivity 重设计）

- 纯净模式：只保留左上返回圆钮、右下"隐藏UI"按钮；背景切换胶囊（星云 / 纯黑 / 世界场景）底部居中。
- 立绘底部环形光台（随 RotationY 联动透视椭圆）；旋转时地面拖出微弱光轨。
- 双指缩放范围 0.8~2.2x；快速滑动松手带惯性衰减旋转（DecelerateInterpolator）。

## 4. 横竖屏与多设备响应式方案

### 4.1 基础设施（当前完全缺失，需新建）

1. 所有页面 `RequestedOrientation` 不锁定；重写 `OnConfigurationChanged`（Manifest 声明 `ConfigChanges.Orientation | ScreenSize`），旋转时重建布局树（现有页面本就是 OnResume 全量重建，成本可控）。
2. 新建 `UI/ResponsiveLayout.cs`：
   - `IsLandscape`、`ScreenWidthDp/HeightDp`、`SizeClass`（Compact <600dp / Medium 600~840 / Expanded >840，对齐 Material 3 WindowSizeClass）；
   - `Columns(portrait, landscape, tablet)` 网格列数辅助；
   - 所有 `UI.Dp()` 调用保持不变，间距按 SizeClass 缩放（平板边距 16→32dp）。

### 4.2 各页面双向布局策略

| 页面 | 竖屏 | 横屏 |
|---|---|---|
| 主页 | 立绘右置、入口左列、底部导航 | 立绘居中偏右，左侧竖导航，活动卡移至右上 |
| 抽卡 | 上立绘下按钮 | 左立绘+法阵，右侧操作面板竖排 |
| 战斗 | 上敌方/中战场/下手牌（手牌扇形收窄） | **主设计**：横向战场，手牌底部扇形展开 |
| 卡组编辑 | 上卡组下卡池 4:6 | 左卡组右卡池 4:6，卡池 6 列 |
| 商店 | 2 列商品 | 3~4 列商品 |
| 设置 | 单列列表 | 双栏：左分组导航，右详情 |
| 列表/图鉴 | 3 列 | 5 列（平板 6 列） |
| 详情 | 底部抽屉 | 左立绘右信息面板 5:5 |

### 4.3 多设备保障

- 全部尺寸走 `UI.Dp()`，禁止像素硬编码；文字 sp 尊重系统字号但上限 1.3x（防爆版）。
- 刘海/挖孔：一级页顶部资源条加 `WindowInsets` 顶部安全边距；战斗页横屏左右加 `displayCutout` 边距。
- 低端机降级：粒子密度三档（设置页可调），Compact + 低画质时关闭视差与常驻扫光。

## 5. 交互动效规范

### 5.1 通用参数

| 类型 | 时长 | 插值器 |
|---|---|---|
| 按压反馈 | 80/120ms | Accelerate / Decelerate |
| 页面转场 | 280ms | FastOutSlowIn |
| 弹窗弹出 | 240ms | Overshoot(1.2) |
| 卡牌翻转 | 400ms | 前半 Accelerate 后半 Decelerate |
| 列表错峰入场 | 单项 240ms，间隔 40ms | DecelerateInterpolator |

全局纪律：动画一律走成员 Handler + OnDestroy 清理（现 PostSafe 模式）；自绘动画 View 必须继承 AnimatedEffectView（不可见即停 Invalidate）。

### 5.2 卡牌翻转（新增核心动效）

`RotationY 0→90°`（显示卡背，CameraDistance = 8000×density 防透视畸变）→ 瞬间换为正面内容 → `90→0°`；SSR/UR 在 90° 换面瞬间触发 ParticleView.TriggerBurst + 稀有度色闪屏（α25%，120ms）。用于：抽卡揭示、图鉴新卡解锁、战斗抽牌。

### 5.3 抽卡演出（升级现有五段式）

聚能（法阵加速旋转+吸入粒子 800ms）→ 稀有度闪（全屏稀有度色 160ms，UR 前置金色双闪"炸金"预告）→ 卡背降临（卡背从上方坠入+尘土粒子）→ 翻转揭示（5.2）→ 立绘爆发（scale 1.3→1 + TriggerBurst + ShineView 扫光）。十连跳过按钮右上常驻（霓虹青幽灵按钮）。

### 5.4 拖拽（战斗出牌 / 卡组编辑）

拿起：scale→1.12、投影 blur×2、微倾斜 3°（跟随拖动方向）；拖动：卡牌以 0.15 插值弹性跟手（非硬跟随）；吸附：进入有效区磁吸 + 目标金圈脉冲；释放成功：卡牌溶解为 30~50 个光粒子飞向目标；释放失败：Spring 回弹原位（Overshoot 1.5）。

### 5.5 粒子特效场景表（复用 ParticleView 三型粒子）

| 场景 | 粒子 | 说明 |
|---|---|---|
| UR 卡常驻 | Stardust 边缘环绕 | 密度低，8~12 粒 |

### 5.6 转场

一级页间（导航切换）：淡入淡出 + 新页 4% 上移；进详情：共享元素缩放（立绘卡→全屏立绘）；进战斗：金色斜切双门合拢→展开（"开战"仪式感，500ms）。
