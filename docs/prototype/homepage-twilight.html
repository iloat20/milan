诸神黄昏 · 东方

Twilight of Gods — 末世交汇的东西方神系重做方案（原型阶段）

① 留白压缩 & 比例优化

顶部状态栏由 38dp 压到 ~12dp，主视觉高度从 230dp 提升到 430dp（约 55% 屏高）；铭牌与按钮间距收紧，取消原"功能导航 2 列网格"的大块空白，改为单行神谱头像横滑，信息密度更高、视线更聚焦立绘。

② 立绘 3D 感 / 漂浮 / 光效

原型用 CSS 演示可落地的代码方案：float 漂浮（±12px 缓动）、rarity 光晕脉动（halo pulse）、rim-light 扫光、鼠标视差伪 3D 倾斜。正式立绘需重绘为带体积光/景深的高质量图（见规范文档）。

③ 统一风格头像

所有头像改为圆形 + 稀有度渐变光环（conic 旋转）+ 内描边，与立绘共用配色，告别旧版方形卡。

④ 立绘基于背景故事

每个角色立绘严格源自其神话原型（烛龙=昼夜、刑天=干戚、凤凰=涅槃…），下方"立绘依据背景故事"条已给出 3 例映射。

⑤ 主题：次元裂缝 → 诸神黄昏·东方

配色：暗紫夜 熔金 霜蓝。融合山海经 + 中国上古神话 + 希腊神系（现阵容以希腊/超英融合呈现，后续扩池引入宙斯、雅典娜等真正希腊神）。
