# Milan 主题是否仍贴合世界观与角色故事？

> Generated 2026-09-12 · depth: standard · 57 findings / ~30 unique sources · workspace: research/milan-theme-fit/
> **决策落地（2026-09-12）**：产品名锁定 **「织环」**；设计语言已升为 v3.1「织环 · Ringweave」，见 `docs/superpowers/design-language/00-design-language-v3.md`。

## Executive summary

1. **用户的判断成立**：「丹青录 / 丹青典藏」作为全产品品牌，与当前三界裂隙叙事、山海经混编 roster、Marvel Snap 工艺卡面**三处同时错位**——不是审美偏好问题，是概念层错配。
2. **国风/水墨在 2024–26 头部产品里几乎从不做全游戏底座**：成功古风抽卡（忘川风华录）明确写「传统人物画不具备大众性，只能锦上添花」；腾讯系水墨只作限时皮肤线 [1][2][7][8]。
3. **多世界品牌靠「叙事总线 + 抽象分类轴」，不靠统一画风**：HSR（星穹列车 + 星神/命途）与 FGO（修复人理 + 特异点编号/职阶）允许区域视觉完全异质 [21][22][23]。Milan 的三界已是合格的 L1；缺的是 L0 品牌动词与可数名词。
4. **混编 roster 的成熟公式是「共享危机 + 召唤机构 + 超文化分类法」**，不是单一文化画风 [31][33][34]。「典藏馆」是机构隐喻，但强调**静态收藏**，与故事主轴「重铸原初之环」的**行动动词**冲突 [35]。
5. **高迁移品牌词是可数名词**（源石 / 英灵 / 神秘学家），同时充当货币、身份与危机产物；不是场所名词（馆 / 录 / 典藏）[41][46]。
6. **推荐首选主题（经王者荣耀对照后微调）**：产品品牌承载**玩家幻想/行动动词**（召英灵 / 织环 / 成为织环者），**不承载文化媒介名**；山海经是**角色内容池**，三界是**区域/势力**，水墨只作 Shinwa 阵营皮肤或活动线——与王者「品牌=王者竞技，文化=英雄池+皮肤线」同构。
7. **不建议**继续把「丹青录」当全站 Logo 与设计语言主张——迁移到 L2（阵营皮肤）成本远低于继续用它撑全产品。
8. **附带风险**：桔梗 / 刻晴等命名与既有 IP 高度撞车 [single source, 本地 lore]，任何主题都躲不开，需单独处理。
9. **品牌名不是锁定资产**：明日方舟中文名在截止压力下后置敲定 [48]——当前「丹青录」可替换。
10. **证据边界**：原神七国、物华弥新/来古弥新、白夜极光等中文一手页面本轮不可达；王者中文官网/百科本轮 403/567，对照主要依据国际服官品牌页 + 既有「墨染江湖」证据 [8][51]。

## Background & scope

Milan 现状：品牌「丹青录」+ 设计语言 v3「丹青典藏 · Gilded Codex」（*整个 App 是一座只陈列珍本的典藏馆*）；立绘却是「山海经 × 现代卡牌标杆」写实/半写实工艺卡面；世界观是裂隙撕裂 Shinwa/Aether/Ironveil 三界，玩家**重铸原初之环**。本报告回答：该主题是否仍贴合；若否，哪些替代主题更贴合世界观与角色故事；迁移代价如何。范围外：代码改名、完整剧本重写、法律意见。

## 1. 错位诊断：三层不一致

### 1.1 品牌承诺 vs 卡面工艺

「丹青」语义指向矿物颜料与传统绘画代称，天然绑定博物馆/古画联想 [11]。而 Milan 立绘管线对标 Marvel Snap 的箔/浮雕/全息**工艺分级**，美学基因更接近西式结构秩序与金属高反，而非中式写意留白 [4][5]。行业铁律要求「特效与界面风格不得割裂」[6]——水墨 UI 与写实稀有度卡面在同一产品里打架，是结构性问题。

雷火（忘川风华录）2026 美术文是关键一手证据：国风只能「锦上添花」，**传统人物画不能作主体**；正确做法是「提取国画技法、保留二次元基底」[1][2][3]。全水墨底座在**模拟经营/收藏品类**（江南百景图）可以成立，但那是另一套玩法承诺 [9]。

### 1.2 隐喻动词 vs 故事主轴

设计语言 v3 把玩家定义为**收藏家/观看者**（展柜、射灯、陈列）。剧情一句话却是：

> 裂隙撕开三界，你在碎片间召唤英灵，把破碎的原初之环重新拼回世界。

动词是 **召唤 / 拼回 / 重聚**，不是「观赏」。对标样本里，玩家职责与叙事职责必须同构：

| 产品 | 玩家职责动词 | 机构隐喻 |
|------|-------------|---------|
| FGO | 守护人理 / 修复特异点 | Chaldea（人理継続保障機関）[31][32] |
| HSR | 开拓 / 乘车旅行 | 星穹列车 [33] |
| 明日方舟 | 救援感染者 / 存续 | 罗德岛 [34] |
| 重返未来1999 | 在暴雨抹除前抢救时代 | 圣洛夫基金会 [42] |
| **Milan v3** | **陈列珍本** | **典藏馆** |

「典藏馆」与「列车/方舟/Chaldea」同属集合机构，但前两者是**行动载具/使命组织**，后者是**静态场所** [35]。

### 1.3 单一文化品牌 vs 异质三界

28 名角色实为混编：山海经正统（烛龙/刑天/女娲/精卫…）+ 域外来客（桔梗/刻晴/雷霆/偃师）+ 铁帷工业改造体 + Marvel/DC「联动」注记。HSR/FGO 的解法不是统一画风，而是**三层品牌**：

```
L0 叙事总线（列车开拓 / 修复人理）
L1 跨区域抽象（星神-命途 / 特异点-职阶）
L2 区域本地化视觉（仙舟中式 / 匹诺康尼西部；卡美洛 / 巴比伦尼亚）
```

区域视觉允许完全不同；统一性由 L0+L1 承担 [21][24]。Milan 的三界已是合格 L1，但品牌名「丹青录」试图用**一种文化工艺**罩住三种异质文明——这正是成功样本刻意避免的。

### 1.4 历史包袱

MVP（2026-07）原为「和忍忍者 / 星灵科幻 / 铁帷赛博」；后全面改写为山海经，品牌名与 UI 未同步换芯到叙事层。四代设计语言叠层（v3 文档自陈）说明「丹青」是**中途贴上的皮肤**，不是从角色故事长出来的主题。

## 2. 市场证据：什么主题装得下混编

### 2.1 中国神话/山海经系

- **Black Myth: Wukong**：品牌 = 西游续写 + 章末多风格 vignette + 鼓笛听觉隐喻；三天 1000 万套 [1][2][4]。失败面是视觉奇观强但叙事/UI 绑定弱导致章节断裂 [3]——对 Milan 的警示：**强美术品牌若缺章节/UI 世界观绑定，读起来像无方向**。
- **Phantom Blade Zero「kung-fu punk」**：表面可去中国化、内核必须中国；用复仇/忠诚/爱等通用主题降低文化门槛 [5][6]。对应 Milan：Ironveil 工业壳可以更「潮」，但山海经内核必须是叙事公约数。
- **山海经视觉方法论**（Nature HSSC 2026）：嵌合体式形体重组（加减/夸张/位移/拼贴），形仿→意仿→文化仿三层递进 [7]。《观山海》证明水墨媒介**可以**重构神话——但那是插画系列品牌，不是强度抽卡底座 [8]。
- **新神话动画**（大鱼海棠/哪吒）：重构符号链承载现代价值观，而非换皮 [9]。

### 2.2 国风水墨的产品力边界

| 用法 | 案例 | 结论 |
|------|------|------|
| 全游戏底座 | 江南百景图（经营） | 可成立，品类不同 [9] |
| 卡面主体 | — | 雷火明确拒绝 [1] |
| 提炼技法 + 二次元基底 | 忘川风华录 | 成功路径 [2][10] |
| 限时皮肤线 | LOL手游兰亭墨韵、王者墨染江湖 | 水墨作套系，不改本体 [7][8] |

**对 Milan 的直接含义**：水墨 token 应降级为 **Shinwa 的 L2 阵营皮肤**，不能再当全站设计语言主张。

### 2.3 混编 roster 收敛公式

从 FGO / HSR / 方舟可归纳（综合归纳，medium confidence）[35]：

1. **共享存亡危机**：人理烧却、星核、源石病 → Milan 已有「裂隙 / 原初之环破碎」✅  
2. **召唤/集合机构**：Chaldea、列车、罗德岛 → Milan 有「典藏馆」但缺使命载具感 ⚠️  
3. **超文化分类法**：职阶、命途×属性、源石技艺 → Milan 有三界+元素，但三界**未兼任玩法分类轴** ⚠️  

域外来客在成熟样本中被写成**机制身份**（被召唤者/旅客/感染者），不是「IP 联动注记」[37]。桔梗/刻晴式撞车命名在 FGO 框架下会被「从者」本体论吸收；在「丹青录」下只会更显眼。

### 2.4 品牌词结构：可数名词 > 场所名词

明日方舟的「源石」同时是能源、魔法、瘟疫、货币、身份；甚至原初源石之一直接命名**娲石**，证明「多界碎片重聚 + 中国神话物质」可在同一命名栈合法并存 [43]。商品层还拆成至纯源石/合成玉/源石碎片三档货币词 [44]。

Dislyte「代行者 Esper」用现代名+神力括注完成跨神话入城，**完全不需要展柜品牌** [45][46]。FGO「英灵」已是中文市场对「神话英雄被召唤重聚」的默认强词 [47]。

**结论**：成功品牌给玩家一个**可数的东西**去持有/供能/重聚；「录」「馆」「典藏」是存放处，不是持有物。

## 2.5 对照王者荣耀：文化是英雄池，品牌不是画种

> 补充调研 2026-09-12。中文官网/百科本轮不可达；以下以国际服官品牌页 [51] + 既有 F3「墨染江湖」证据 [8] 为主，部分结构归纳标 [speculative]。

### 2.5.1 王者品牌怎么分层

| 层 | 王者做法 | 对 Milan 的含义 |
|----|---------|----------------|
| **L0 产品品牌** | 「World's Most-Played 5V5 Mobile MOBA」/ 王者——承载**竞技称王**幻想，不是国画/博物馆 [51] | 品牌名应说清「你来干什么」（召英灵/织环/登临），不要用文化媒介名 |
| **角色内容池** | 历史/神话英雄（李白、妲己、孙悟空…）+ 原创 + 全球神话；官文案强调「mythological legends, legendary stories」[51] | 山海经 = Milan 的**内容池**，不是 UI 皮肤 |
| **玩法分类轴** | 战士/刺客/法师/射手/辅助——与出身文明解耦 [51] | 稀有度+元素+职能可独立于三界；三界不必兼任唯一分类 |
| **区域/势力** | 王者大陆上的长安、长城守卫军、稷下、三分、云中漠地… [speculative，本轮未取到中文设定页正文] | Shinwa/Aether/Ironveil = L2 区域势力，允许视觉异质 |
| **文化美学** | 基底是现代竞技 UI；国风/水墨以**皮肤线**出现（墨染江湖=平行世界套系，不改英雄本体）[8] | 丹青/朱印/绫绢 → Shinwa 皮肤或活动线，**不做全站 chrome** |
| **世界观叙事** | 国际服自述「years of updates to character designs, worldview narratives…」——叙事服务角色与长线，不是产品名 [51] | 三界裂隙叙事可继续加厚；不必绑进 Logo |

### 2.5.2 可直接迁移的三条纪律

1. **品牌动词优先于文化名词**  
   「王者」说的是玩家状态；「丹青录」说的是颜料与图录。抽卡侧对应动词应是**召 / 聚 / 织 / 登临**，不是**录 / 藏 / 观**。

2. **神话角色可以「进现代场」**  
   王者让李白/孙悟空进 5V5 现代竞技场而不改写产品为「唐诗录」；Milan 可让山海经英灵进裂隙战场而不改写产品为「丹青录」。文化自信在**角色内容与皮肤**，不在 chrome 配色。

3. **平行世界用皮肤线表达，不用换产品名**  
   墨染江湖、山海经皮肤证明：水墨是**可售卖的审美套系**，不是底座 [8]。对应 Milan：未来可出「丹青」限定卡面/界面主题包，但主品牌仍是行动向。

### 2.5.3 与既有推荐的关系

王者对照**强化**而非推翻首选「原环·织环者」：

- 若希望更「国民/热血」向，可把 L0 写成更短的行动四字（候选见 §3.2），叙事内核仍是原环。
- 若希望更「收藏叙事」向，保留织环者身份 + 环痕可数名词即可，不必回到「典藏馆」。
- **明确否定**「学王者把产品叫成画种/朝代名」——王者从未把产品命名成《水墨》《大唐》。

## 3. 主题候选与推荐

### 3.1 适配度排序（对「裂隙三界 + 英灵重聚」）

| 排序 | 范式 | 代表 | 与 Milan 契合 |
|------|------|------|---------------|
| 1 | 物质锚点（可数名词） | 源石 / 娲石 | 环痕=货币+身份+危机产物 |
| 1 | 英灵召唤（本体论） | FGO | 文案已用「召唤英灵」 |
| 3 | 时间/灾难抢救 | 1999 | 动词对，但时间线叙事要新建 |
| 4 | 神话凭依 | Dislyte | 适合来客，弱化三界地理 |
| 5 | **展柜/丹青典藏** | Milan v3 | **最弱：把玩家定义为观看** [46] |

### 3.2 首选：「原环 / 环痕 · 织环者」行动型品牌

**概念主张**：世界曾是一枚完整的**原初之环**；裂隙把它打碎成三界。你不是馆长，是**织环者**——把散落的环痕召回、拼合、重铸。

| 层 | 命名建议 | 说明 |
|----|---------|------|
| 产品名（L0） | 候选：《织环》《环纪》《召灵》《聚英》《原环》 | 短行动/身份向（王者式：品牌说清「你来干什么」）；避免「录/馆/典藏」 |
| 玩家身份 | 织环者（叙事文档已有，可升格） | 与「拼回原初之环」同动词 |
| 角色本体 | **英灵**（沿用）/ 环使 | 复用中文强词 [47] |
| 物质/货币 | 环痕 · 残玦 · 纯环（对应源石三档） | 抽卡/碎片/付费同源 [44] |
| 集合机构 | 织环台 / 回响枢 / 裂隙站（行动向，非展厅） | 对标列车/Chaldea |
| 三界 | 保留 Shinwa / Aether / Ironveil 作 **L1** | 区域视觉完全异质 |
| 水墨/朱印 | **仅 Shinwa 的 L2** | 全站降级，不作品牌主张 |

**为何贴合**：危机（环碎）、动词（织/召/拼）、可数名词（环痕）、机构（织环台）四件套齐；28 角可原样收编为「三界英灵 + 环痕共鸣者」；工业铁帷与星图以太不再被迫穿丹青外衣。

**迁移成本**：中低。改 Logo/BrandType 文案、商店货币显示名、主页副标题；`丹青录` 字符串与楷书 Logo 槽保留可作活动回响；v3 的工艺稀有度、玻璃面板、动效骨架**可继承**（它们本就不依赖水墨）。

### 3.3 备选 A：「山海残卷」——改造而非抛弃丹青

若必须保留古典中文调性：

> 不是「只陈列珍本的馆」，而是**一卷被裂隙撕碎的山海图志**；玩家修复残页，每一页是一位英灵。

- 玩家动词：修复 / 补页 / 展卷（比「观看」主动）  
- 水墨可保留在**卷面材质与 Shinwa 插图**；Aether/Ironveil 页允许异质画风（残卷本就可拼贴异域图式——呼应山海经嵌合体方法论 [7]）  
- 成本：低（品牌词微调 + 设计语言主张句改写）；风险：仍偏「书/物」，战斗与裂隙战争气质偏文弱  

### 3.4 备选 B：「山海工业 / kung-fu-punk 神话」

对标 Phantom Blade Zero：表面 Ironveil 潮酷工业，内核山海经 [5][6]。适合强化铁帷卖点，**不适合**当全产品品牌——会边缘化 Shinwa/Aether。可作为 Ironveil 活动季主题。

### 3.5 明确不推荐

- **继续「丹青录」作全站品牌**：三处错位均有证据支撑（§1）；继续只会加深「UI 和卡面打架」。
- **ZZZ 街潮**：与 28 张山海经写实立绘冲突；v3 已否决，维持。
- **再造「博物馆/图鉴」同义词**（神谱馆、英灵陈列馆）：仍是场所名词 + 被动动词 [46]。
