# Research Brief — Milan 主题与世界观贴合度

> 日期：2026-09-12
> 深度：standard（3–5 个并行角度，1 轮补查，目标 15+ 来源）
> 产出：`research/milan-theme-fit/REPORT.md`

## 1. 研究问题

**「丹青录 / 丹青典藏」这一品牌主题，是否仍能承载当前三界世界观与 28 名角色故事？若不能，哪些替代主题更贴合？**

决策在用：是否重命名/重定向品牌与 UI 设计语言；角色 roster 是否需要收敛；下一版视觉与叙事往哪条主线推。

## 2. 项目事实（本地材料，不靠外部搜索）

| 项 | 现状 |
|---|---|
| 品牌名 | **丹青录**（首页 Logo、CI 品牌条、楷书 BrandType） |
| 设计语言 | v3「丹青典藏 · Gilded Codex」——概念主张：*整个 App 是一座只陈列珍本的典藏馆*；水墨从装饰层退为馆内氛围层 |
| 立绘管线 | v2.2/v2.3「山海经 × 现代卡牌标杆」——写实/半写实卡面 + Marvel Snap 工艺稀有度，**不是**传统水墨画 |

| 角色构成 | 28 角：多数为山海经原型（烛龙/刑天/女娲/精卫/凤凰…）；混有域外来客（桔梗、刻晴、雷霆、偃师等）与 Marvel/DC「联动」注记 |
| 叙事冲突轴 | 烛龙 vs 虚无；刻晴 vs 烛龙（人定胜天 vs 神明回归）；铁帷内战（兵主武器化） |
| 历史包袱 | MVP（2026-07）原为「和忍忍者 / 星灵科幻 / 铁帷赛博」三世界；后全面改写为山海经，但品牌名与 UI 未同步换芯到叙事层 |

### 2.1 已观察到的错位（假设，待研究验证/反驳）

1. **命名与画种**：「丹青录」指向传统书画图录，而立绘是现代卡牌插画。
2. **命名与叙事**：典藏馆隐喻强调「静态收藏」，故事是「裂隙战争 / 重铸原初之环」。
3. **三界异质**：神話可挂水墨；以太星图、铁帷工业金属很难挂「丹青」。
4. **角色混编**：山海经正统 + 日系/原神系客串 + 工业改造体，单一「东方书画」主题装不下。
5. **IP 安全**：桔梗/刻晴等命名与人设高度撞车既有 IP，主题再怎么定也躲不开。

## 3. 范围

**In scope**
- 品牌/主题概念（名称、隐喻、一句话主张）与世界观、角色故事的贴合度
- 市场上可对标的手游品牌系统如何处理「多世界 + 混编角色」
- 2–4 条可行替代主题方向（含保留并改造丹青录的路径）
- 各方向对现有资产（28 立绘、水墨 UI token、三界文案）的迁移成本粗估

**Out of scope**
- 具体代码实现、Compose 组件改名
- 完整角色重写剧本 / 数值系统
- 商业发行、买量素材
- 版权诉讼意见（仅标风险信号，不给法律结论）

## 4. 假设

- 用户核心不满是「主题装不下故事」，不是单纯不喜欢「丹青」二字。
- 28 张立绘与三界框架是沉没成本较高的资产，优先找**能包容**的主题，而非推倒角色。
- 报告面向项目决策（主题选型），不是玩家调研报告。
