# F4: 角色 roster 主题收敛方案

## Findings

### [1] 市场成熟做法不是「统一画风/统一文化域」，而是「共享使命 + 召唤/集合机构 + 跨源分类法」；FGO 的 Chaldea 把魔法与科学写进同一使命文本，用「人理守护」压过题材异质
- quote: "魔術であれ科学であれ、それを研鑽する人間がより長く繁栄すること―――即ち、人類史の守護である。人理継続保障機関・カルデア。…人類史を何より強く存続させる尊命の下に、魔術・科学の区別なく研究者が集められた。"
- url: https://www.fate-go.jp/world/1st/
- source_type: primary
- published: unknown (live site, accessed 2026-09-12)
- confidence: high

### [2] FGO 用「守护英灵召唤系统·FATE」把跨文化历史人物收进 roster：不同时代/文明的英灵被同一召唤机制纳入，靠职阶（Saber/Archer/…/Extra）而非文化域做统一分类
- quote: "集うは歴史に名を刻む英霊たち"；官页列 Saber/Archer/Lancer/Rider/Caster/Assassin/Berserker/Extra 八类；Saber 示例含不列颠传说之王阿尔托利亚、匈奴大王阿提拉、圆桌骑士高文、伊势刀工千子村正
- url: https://www.fate-go.jp/servant/
- source_type: primary
- published: unknown (live site, accessed 2026-09-12)
- confidence: high

### [3] FGO Part 2「Lostbelt 异闻带」把「异质文明并置」做成主叙事单元：每个 Lostbelt 是被正史淘汰的平行人类史（永久冻土帝国、人智统合真国、神代巨神海洋、妖精圆卓领域等），文化异质被解释为「败者的历史」而非联动
- quote: "過った選択、過った繁栄による敗者の歴史。『不要なもの』として中断され、並行世界論にすら切り捨てられた『行き止まりの人類史』――これを、異聞帯ロストベルトと呼ぶ。"
- url: https://www.fate-go.jp/world/cil/
- source_type: primary
- published: unknown (live site, accessed 2026-09-12)
- confidence: high

### [4] 《崩坏：星穹铁道》用「星穹列车旅客」作为跨世界收集容器：玩家与「开拓」意志同伴穿行无数世界，角色异质（空间站科技/冰封星球/巨型舰队/长生种联盟）被统一为「旅伴」而非同一文明出身
- quote: "你——一名特殊的旅客，将与继承「开拓」意志的同伴一起，乘坐星穹列车穿越银河…造访寓居宇宙的万象世界，携手形形色色的旅伴，解救「星核」引发的种种危机，对抗「星神」践踏文明的意图。"
- url: https://wiki.biligame.com/sr/崩坏：星穹铁道
- source_type: secondary
- published: 2026-07-29 (wiki page last edited)
- confidence: high

### [5] HSR 的 roster 统一层不是世界观地理，而是「命途 Path × 属性 Element」双重分类：毁灭/巡猎/智识/同谐/虚无/存护/丰饶/记忆/欢愉 九命途 + 物理/火/冰/雷/风/量子/虚数 七属性；任何世界的角色都先挂到这套抽象坐标上
- quote: "毁灭 兼具不俗的输出与生存能力…巡猎 有着非凡的单体攻击能力…存护 具备强大的保护能力…丰饶 能够治疗我方伤势"
- url: https://wiki.biligame.com/sr/命途
- source_type: secondary
- published: 2026-08-24 (wiki page last edited)
- confidence: high

- Google / DuckDuckGo / Wikipedia / Fandom (typemoon, fategrandorder, honkai-star-rail) / Zhihu / 百度百科：全部 Transport error 或 403，未能引用
- Bing 中文/英文搜索大量返回无关页（美图秀秀、搜狗输入法、关税 PDF、直播平台等），未作为证据

- 直连白荆回廊/深空之眼官方或 biligame wiki，验证「多世界交汇城市/回廊」作为集合机构的命名与文案
