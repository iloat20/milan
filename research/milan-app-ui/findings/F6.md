# F6 — 设计系统

> 设计语言：**丹青典藏 · Gilded Codex v3**（2026-09-09）——App 是一座只陈列珍本的典藏馆，卡牌是文物，界面是展陈系统。色彩三层：基底（玄墨）/ 材质面（玻璃）/ 强调（金箔 + 朱砂）；禁止第四层氛围色。全站唯一稀有度取色口是 `AppTheme.rarityColor`。

## Motion language

1. **按压**：`inkPress`/CodexCard scale **0.96–0.965 + spring**（damping MediumBouncy 或 0.65）；GoldSwitch 轨道微扩 46→50dp。
2. **列表入场**：`EntranceItem` 交错 40ms×index（封顶 8），alpha 260ms + translateY 26px，300ms Linear；appear 以组合身份 remember，滚动不重放。
3. **对话框**：`GlassDialog` fadeIn 200 + slideInVertically(h/8) + scaleIn 0.95，spring damping 0.7。
4. **卡牌工艺动效**：SSR 辉光呼吸 1800ms Reverse（α 0.28↔0.58）；UR 箔面扫光 4200ms Linear 往返。
5. **立绘共享元素**：`SharedTransitionLayout` + `LocalSharedTransitionScope` 注入；`CharacterCard` 立绘 `sharedBounds(key="portrait_$id", ResizeMode.RemeasureToBounds)`；null 时降级普通渲染。
6. **导航**：底部 5 tab + 类型安全路由；子页盖住 tab，系统/Predictive Back 逐层退出。
7. **触觉语言**（`HapticManager` 分层）：
   - LIGHT：按钮点击 / 开关
   - MEDIUM：抽卡蓄力 / 普通确认
   - HEAVY：抽卡揭晓 / 暴击
   - RICH：UR 获得 / 击杀（Envelope，设备支持时）
8. **抽卡舞台节奏**：Idle → Charge（蓄力）→ Beam（光柱）→ Single/Ten（揭晓）；rarity≥2 叠 Mesh+粒子；SSR+ 翻牌 CONFIRM/LONG_PRESS buzz + `MilanAudio.playSfx("gacha_reveal")`。

## Open gaps

1. **无 Light Theme**：`InkColors` 仅 darkColorScheme；`useDarkTheme=false` 时若未开动态取色仍落到同一套深色。产品层「深色沉浸」是刻意选择，但缺少 light token 面板。
2. **`DynamicTheme` / `parallaxScroll` / `parallaxBackground` 零调用**：库已写好、无 Screen 接入；元素氛围实际靠 `ElementTheme.forElement` 就地取色，CompositionLocal 路径未启用。
3. **`BattleHapticEffect` / `GachaHapticEffect` / `hapticClick` / `hapticToggle` 在 Screen 层几乎未接线**：GachaScreen 用 View 级 `buzz()`，按钮用 clickable 无统一 haptic 修饰符；HapticManager 能力大量闲置。
4. **Glance 色值与 AppTheme 漂移**：widget 自称对齐，实际 GOLD/Text1/Text2 与权威 token 不完全相同（改色板需手动同步，注释已警示）。
5. **`InkSnackbar` 与 `LocalFeedback` 双轨**：自定义 Snackbar 组件存在，但主链路已迁 Material SnackbarHost（Feedback）；InkSnackbar 可能成为死代码。
6. **打字体系仍有裸 fontSize**：v3 要求「新代码禁止裸 fontSize」，但 EmptyState（16/13sp）、GlassDialog（18/13sp）、CharacterCard 部分 label、按钮 `textSize` 参数仍在档位外。
7. **`DamageFloatingText` 的克制判定是简化版**（`damage > 0` 即金），注释已标明；与真实克制逻辑未对齐。
8. **`LocalWorldPalette` 注入点有限**：文档写「详情页/主页 Hero」，需确认 Home 是否实际 CompositionLocal 包裹（CharacterDetail 有 `WorldTheme.forWorld`）。
9. **粒子/AGSL 性能**：FluidBackground 节流 45ms + RESUMED 门控已做；大屏全屏 Mesh + 多层粒子在低端机未见 quality tier 降级策略。
10. **`BattleHitSparks` 预设仍有硬编码色**（`0xFFFFD700` 等），未走 EffectPalettes（与 v3「禁止硬编码」张力，虽非稀有度色）。
