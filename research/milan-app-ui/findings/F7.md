### 无「确认购买 / 确认抽卡」对话框

- **Shop**：四类购买/兑换（每日特惠 / 碎片包 / 碎片兑换 / 钻石兑换）均为**一键直购**，无二次确认。防重入靠 `ShopViewModel.busy`；affordability 在按钮 `enabled` 上钳制；结果走 `toasts` → Snackbar。
- **BattlePass**：「购买豪华版 680💎」同样直购，无确认框（`BattlePassScreen` + `BattlePassViewModel.purchasePremium`）。
- **Gacha**：`单 抽` / `十 连` 直接 `vm.doPull`；余额预检 `softCurrency < cost → onError("星尘不足")`；无确认对话框；演出中 `BackHandler` 跳过 reveal。
- **Affinity 送礼**：卡片按钮直送，无确认；满级/余额不足在 VM 校验后 toast。

## Global feedback

### 正式通道：`LocalFeedback` + 全局 `SnackbarHost`

- 定义：`ui/feedback/Feedback.kt` — `Feedback.show(message)` 委托 `SnackbarHostState.showSnackbar`；`LocalFeedback` compositionLocal，未提供时 `error(...)` fail-fast。
- 宿主：`MilanNavHost.kt:142–144, 341–352` — `SnackbarHost` 置于 `BottomCenter`，`padding(bottom = 84.dp)`（浮在 `GameNavBar` 上方）；`containerColor=BgMid, contentColor=Text1, actionColor=Gold`。
- 统一 VM 模式（几乎全站）：
  ```
  // VM
  private val _toasts = Channel<String>(Channel.BUFFERED)
  val toasts: Flow<String> = _toasts.receiveAsFlow()
  // Screen
  LaunchedEffect(vm) { vm.toasts.collect { feedback.show(it) } }
  ```
  覆盖：Shop / Settings / Story / Achievement / Affinity / Arena / BattlePass / DailyMission / Deck / Progression / CharacterDetail（装备穿脱强化分解）。Gacha 在 `doPull` 的 `onError` 回调里直接 `scope.launch { feedback.show(msg) }`。
- 文案套路：成功短句（「已获得…」「已兑换…」）/ 拒绝原因（「星尘不足」「该宝箱已领取」）/ 统一落盘失败「保存失败，请重试」。

### 残留系统 Toast

- 仅 Crash 复制成功：`HomeScreen.kt:626` `Toast.makeText(..., "已复制到剪贴板", SHORT)`。Feedback.kt 注释明确曾用 Toast 的 Gacha/Shop/Settings 已收敛。

### 触觉 / 音效

- `HapticEffects.kt` 提供 `Modifier.hapticClick/hapticToggle`、`GachaHapticEffect`、`BattleHapticEffect`（封装 `HapticManager`），但**当前 Screen 层几乎不调用这些 Compose 封装**。
- 实际在用：`GachaScreen` 直调 `HapticManager`（UR special / CONFIRM / KEYBOARD_TAP / CLOCK_TICK 按最高稀有度分级）+ `MilanAudio.playSfx("gacha_pull")`；受设置项 `meta.vibrationEnabled` 门控。
- `GoldSwitch` / `GameNavBar` 用弹簧缩放/位移作视觉反馈，不走 haptic 封装。

## Cross-screen UX conventions

### 返回 / 导航

| 模式 | 行为 |
|------|------|
| 主 tab | `GameNavBar` 切换；`AppTopBar` 在 Shop/Settings/Deck 上的 onBack 是 `onNav(Home)`（回 Home tab） |
| 子页压栈 | `AppTopBar` 左上 48dp「‹」+ contentDescription「返回」→ `navController.popBackStack()`；系统/Predictive Back 由 Navigation 自动接管 |
| 角色详情 ↔ 养成 | `switchCharacter` 用 `popUpTo(current)+inclusive` 替换 entry，左右切角色不堆栈 |
| 演出拦截 | Gacha reveal 中 `BackHandler → skipReveal`；Deck 角色预览 `BackHandler → onClose` |
| 深链 | Glance 小组件 `openGachaOnStart` → 启动即切 Gacha tab |

### 空态 `EmptyState`

统一组件：可选 Material outlined icon + title + subtitle + 可选 `NeonButton` action。用例：

- Tower：「还没有出战编队」→ action「前往编队」→ `onOpenDeck`。
- CharacterList / Deck：空列表提示（无 action 或弱 action）。
- Collection：筛选无结果「没有符合条件的角色 / 试试调整筛选条件」。
- 规范注释：v3 §5.5 禁用 emoji 作图标。

### 错误 / 失败

- 启动失败：`InkErrorScreen` 全屏 + 重试（唯一出口）。
- 写操作失败：一律 Snackbar 文案，**无错误对话框**（除策略战斗 `GlassDialog` 与爬塔内联文字）。
- 资源不足：按钮 `enabled=false`（affordable 预检）+ 点击后的 toast 拒绝原因。
- 角色 id 失配：`MissingCharacter` 全屏 + 返回胶囊。

### 加载

- 进程门控：`GameState.ready` 前整棵 NavHost 不组合，只显示 `InkSkeleton()`（shimmer 条 +「加载中」）。
- 无 per-screen 全局 spinner；列表/卡片用 `InkShimmer` 可嵌套，当前主要只在启动门控使用。
- 写操作 `busy`：按钮文案切换（如 Tower「战斗中…」）或直接 `enabled=!busy`。

### 确认范式

- **仅破坏性操作**有二次确认：目前唯一 `ResetSaveDialog`（重置存档）。
- 货币消耗类（抽卡、商店、纪行豪华、好感送礼、爬塔门票）**均无确认框**，靠按钮文案展示费用 + 余额预检 + Snackbar 结果。

### 主题控件

- `GoldSwitch`：熔金开关，替代 Settings 残留 Material Switch；`Role.Switch` 语义；轨道 46→50dp 弹簧微扩。
- `GoldButton` / `NeonButton`（`ThemeButtons.kt`）：主/次动作；EmptyState action、GlassDialog buttons、商店购买统一用它们。

## Open gaps

1. **Home「查看全部」目标错误**：`onOpenCharacter("")` 进 `CharacterDetailRoute("")` → `MissingCharacter`，应导航 `CollectionRoute` 或 `CharacterListRoute`（`HomeScreen.kt:471`）。
2. **`InkBottomSheet` / `InkSnackbar` / `InkTooltip` 为死代码**：与 `LocalFeedback` 路线冲突；要么删除，要么把 `InkSnackbar` 升级为 `Feedback` 的视觉实现（目前 SnackbarHost 用的是朴素 Material3 `Snackbar` + 主题色）。
3. **`HapticEffects` Compose 封装未接入**：战斗胜利/暴击/升级等 `BattleHapticEffect` 无调用点；抽卡走 Screen 内联 `HapticManager`，两套触觉路径未统一。
4. **消耗型操作零确认**：抽卡十连、商店大额、纪行 680 钻石均一键；若产品需要防误触，需新增确认层（当前唯一确认范式是 `GlassDialog` + NeonButton 取消/确定）。
5. **双份结算 UI**：爬塔同时有内联 `TowerResultCard` 与全屏 `BattleResultOverlay`（Completed 时都可见），层级/是否只保留其一待产品定夺。
6. **ResourceBar 与 Shop ResourcePanel 符号/字段不完全同构**：HUD 只显示 soft/hard；碎片/战票仅 Shop；Gacha 页局部再画资源——三处展示逻辑未抽成单一 CurrencyHud。
7. **Snackbar 无类型分级**：`LocalFeedback.show` 只有纯文本；`InkSnackbar` 的 Info/Success/Warning/Error 四色若要做语义反馈需先接线。
8. **启动骨架屏不可重试动画**：`InkSkeleton` 无超时/失败态切换，失败依赖 `GameState.failure` 切 `InkErrorScreen`；正常加载时长不可见进度。
