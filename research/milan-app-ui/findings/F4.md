## DialogueScreen — 视觉小说对话

- **目的**：逐句播放关卡对话（打字机 + 自动播放 + 分支选择），完结发奖。
- **入口**：Story 点关卡 → `DialogueRoute(stageId)`（`MilanNavHost.kt:278-305`）；`stage` 由共享 `StoryViewModel.findStage` 解析。
- **布局**：全屏 `Box`：

  - 中：控制栏（自动播放 toggle、速度 1/2/3/5 秒、跳过）

- **关键组件**：`DialogueLine` / `StoryChoice`（text / affinityBonus / nextStageId）；`getSpeakerName` 硬编码 UR 四名（烛龙/虚无/刑天/饕餮）+ fallback；`getCharacterRarity` 由 id 前缀推断；`getSpeakerColor` 按角色主题色。

## Common patterns across activity pages

1. **导航**：全部为 `@Serializable` 子页路由压栈盖 tab；Home `QuickActions` 横滑 chip（图鉴/爬塔/剧情/日常/纪行/好感/成就/竞技/活动）是主入口；PullHistory 仅从 Gacha 进。
2. **VM 化（P1-6）**：派生状态进 ViewModel，`init { service.snapshot.collect { rebuild } }` 等价旧 `remember(snapshot.revision)`；Screen 纯渲染 + 透传回调。
3. **写操作三态**：`WriteOutcome.Success/Rejected/SaveFailed` → `Channel<String>` toasts → `LaunchedEffect { collect → LocalFeedback.show }`；busy 防连点。
4. **视觉壳**：`PageBackground` + `AppTopBar` + `GlassPanel`/Surface 卡 + `GoldButton`/`NeonButton`；列表统一 `LazyColumn` + spacedBy 8–12dp + contentPadding。
5. **奖励展示**：emoji/icon 映射（BP itemId 前缀、Story soft/hard、成就 reward 拼接）；进度用 `LinearProgressIndicator` 或自绘金色条。
6. **空态**：`EmptyState`（Tower 编队、Collection 筛选）或内联占位文案（PullHistory、Event）。
7. **入场动画**：`EntranceItem(index)` 用于 Achievement / PullHistory / Tower 纪录卡。

## Open gaps

1. **Event 任务进度硬编码**：`EventScreen.kt:133` 未完成时显示 `"0 / ${task.target}"`，未读服务层 `progress`/`current` 字段——任务进度永远 0。
2. **Dialogue 说话者硬编码**：`getSpeakerName` / `getCharacterRarity` / `getSpeakerColor`（`DialogueScreen.kt:480-506`）按 id 前缀与四个 UR 名写死，内容表新角色需改代码。
3. **Affinity 等级奖励为装饰文案**：`AffinityInfoCard` 的 Lv1/3/5/8/10 奖励（语音/剧情/头像框/皮肤/称号）无服务层解锁判定，纯展示。
4. **Arena 无结算演出**：挑战结果仅 Snackbar，无战报/奖励可视化覆盖层（对比 Tower 的 `BattleResultOverlay`）。
5. **BattlePass 经验阈值写死**：`exp / 1000f` 与购买价 `680` 在 UI/VM 就地写，未集中到 EconomyFormulas 风格常量（服务侧是否另有定义未在此角核对）。
6. **PullHistory 无分页/筛选**：固定最近 100 条倒序，无稀有度/池筛选与导出。
7. **Story 章节进度不随完成实时刷新**：`isChapterUnlocked`/`chapterProgress` 在卡片内 `remember { }` 取一次，未订阅 snapshot——本页内完成关卡返回后可能不刷新（需重进或 revision 触发父级重组时才更新）。
8. **DailyMission 不在本角范围**：Home「日常」入口存在（`DailyMissionRoute`），文件在 `ui/missions/`，F4 未展开。
