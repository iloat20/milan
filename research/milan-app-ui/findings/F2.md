# F2 — 主 Tab 页 UI

> 范围：底部五 Tab（Home / Gacha / Deck / Shop / Settings）+ 抽卡演出视觉族。
> 路由宿主：`MilanNavHost`（Navigation Compose 2.9 类型安全路由，`startDestination = HomeRoute`）；tab 切换走 `navigateToTab`（`saveState/restoreState`），子页压栈盖 tab。
> 文件基线：`MilanKotlin/app/src/main/java/com/milan/game/ui/`。

## 1. Home — 丹青典藏馆大厅

### 目的一句话
首屏展柜大厅：一条主行动（召唤）+ 快捷入口横滑 + 丹青名录，作为全 App 的内容与导航枢纽。

### 布局结构（从上到下）
1. `Box(fillMaxSize)` 根：
   - `FluidBackground` 全屏流体墨底（GPU/Canvas 动态背景）
   - `Column` 主体：
     - **品牌条 Row**（statusBarsPadding）：左「丹青录」`BrandType` 金字 + 小字 `COLLECTION`；右 `ResourceBar()`

       - 金色主 CTA `GoldButton("前往召唤")`

2. 浮层：`CrashDialogIfAny()`（上次异常退出现场回显）

## 2. Gacha — 丹青寻访（抽卡）

### 目的一句话

2. `Column(verticalScroll)` 主内容（入场 alpha 450ms）：

### 用户交互

- 「历史 ›」→ PullHistory 子页
- 多池 chips 切换（`rememberSaveable` 持久化 selectedPoolId）

### 视觉特色
- 水墨演出色板 `CyberPalette`：Cyan=SealRed 朱砂 / Magenta=Gold 金箔 / VioletGlow=Frost 石青 / BeamCore=宣纸白（命名历史遗留赛博）

- 分享图：浓墨底 + 金箔顶线 + 稀有度描边圆角格 + 落款「共 N 抽 · SSR+ X ✦ Milan」

- **`ResourceBar`**（AppChrome.kt:142-158）：星尘✦ 金 + 钻石◆ 霜蓝；订阅 `AppGraph.service.economy` 切片；数值 400ms `animateIntAsState` 滚动；`formatCount` 千分位。
- 出现位置：Home 品牌条右、Gacha 标题行右、`AppTopBar(showResource=true)` 默认右（Deck/Shop/Settings 顶栏实际未开？——Deck/Shop/Settings 用的是 `AppTopBar` 默认 `showResource=true`，因此三者顶栏也带 ResourceBar）。
- Shop 额外有完整四资源 `ResourcePanel`（+碎片❖ +战票⚔）。
- 符号约定（P2-5）：✦ 星尘 / ◆ 钻石 / ❖ 星魂碎片 / ⚔ 战票。

### 页面骨架
- 主容器：Home 用 `FluidBackground`，其余四 tab 用 `PageBackground`（BgDeepest→BgMid→BgDeepest 三段竖渐变）。
- 顶栏：Home 品牌条（无返回）；Deck/Shop/Settings 用 `AppTopBar`（48dp 返回热区 + AnimatedContent 标题 + alpha 呼吸金影）；Gacha 自绘标题行。
- 底栏：五 tab 均在页内内嵌 `GameNavBar`（非宿主级 Scaffold bottomBar）。玄墨玻璃 Row + 5 等宽 `NavCell`；选中金箔面板 + 顶部金线弹射 0→32dp + selectScale spring 0.92→1；按压缩放 0.94；semantics Role.Tab + Selected。
- Tab 路由：`navigateToTab` 标准 bottom-nav（saveState/restoreState）；tab 间转场 `InkTransitions.tabEnter/tabExit`；子页左右滑墨迹转场。

### Empty states
- 统一组件 **`EmptyState`**（EmptyState.kt:32-84）：Material outlined 图标 48dp Text3 + 标题 Text2 16sp + 副标 Text3 + `NeonButton` 金色 action。
- 主 tab 内仅 Deck 用到（空拥有列表 → 引导去 Gacha）。Shop/Settings/Gacha 无空态分支；Home featured 空时 VM 塞占位 `CharacterDataEntry("placeholder")`。

### Loading
- App 级：`MilanNavHost` 在 `GameState.ready==false` 时整树不组合，显示 `InkSkeleton`；`failure!=null` 显示 `InkErrorScreen`（可重试 `ensureInitialized`）。
- 主 tab 页内 **无独立 loading 骨架**：VM 初值即为快照同步 `buildState()`，内容/存档已在 Application 预载。
- Gacha 演出 busy 期间按钮 `enabled=false`（alpha 0.45）。
- Settings AI 推荐用 `produceState` 初始空/后填。

### Error handling / Feedback
- 统一 **`LocalFeedback`**（MilanNavHost 注入 SnackbarHostState）：五 tab 写操作结果全部 `feedback.show(msg)`，不再 Toast。
- VM 模式：`Channel<String> → receiveAsFlow()` toasts；Screen `LaunchedEffect(vm) { vm.toasts.collect { feedback.show(it) } }`（Deck/Shop/Settings）。
- `WriteOutcome` 三态：Success（通常静默，靠快照刷新）/ Rejected（业务拒绝文案）/ SaveFailed（「保存失败，请重试」）。
- Gacha 额外：`PullOutcome` Rejected/SaveFailed；余额不足前置「星尘不足」；异常 catch「抽卡异常，请重试」。
- Home 唯一保留 `Toast`：崩溃报告复制成功提示（HomeScreen.kt:626）。
- 防重入：所有写路径共享 VM 内 `busy` MutableStateFlow（Shop 四类写共用一个；Deck toggle 共用）。

### 按钮 / 面板语言
- `GoldButton`：熔金三段渐变 + CutShape + 禁用 alpha 0.45 + inkSplash
- `NeonButton`：透明底 + 色描边 + 内发光；Danger/Frost/Gold/Text2 可调
- `GlassPanel`：玄墨实底 + 发丝线边框 + 顶部内高光；`highlighted` 金边
- `EntranceItem`：列表交错入场（≤8 档 ×40ms）
- 稀有度：`AppTheme.rarityColor(rarity)` / `rarityName`（R/SR/SSR/UR）全 App 统一

### 状态订阅口径
- 一律 `viewModel(factory = AppGraph.factory)`，构造函数必填 `GameService`。
- 订阅方式分两类：
  1. **snapshot 整包重算**：Home / Deck / Shop（`service.snapshot.collect { buildState() }`）
  2. **切片透传**：Gacha（economy/gachaSlice/meta）+ Settings（meta）
- UI 纯态（previewId、selectedPoolId、showResetDialog）留 Screen `rememberSaveable`。

## Open gaps

1. **Home 名录「查看全部」空 id**：`onOpenCharacter("")` 看起来是占位；NavHost 的 `openCharacter(id)` 会照常 `navigate(CharacterDetailRoute(""))`，详情页对空 id 的表现未在本角覆盖，存在空串路由风险。
2. **主 tab 内嵌 GameNavBar vs Scaffold**：五 tab 各自包 bottom bar，非宿主级 Scaffold；与 Material 标准 tab 架构不一致，但状态保存靠 Nav options 补齐。若未来加「盖 tab 的全屏子页」，bar 隐藏逻辑需各页自行处理（当前子页无 bar）。
3. **ResourceBar 未覆盖碎片/战票**：Home/Gacha 顶栏只显示双资源；Shop 有四资源面板但不在顶栏；玩家在 Gacha 消耗星尘时看不到碎片变化（设计取舍还是缺口？）。
4. **Shop 无购买确认弹窗**：与 Settings 重置形成对比；误触直接扣款（busy 防的是连点不是误触）。
5. **Settings AI 推荐无下钻**：`recommendCharacters` 显示 top3 原因首条 + 评分，但不可点进角色详情/养成；`recommendGacha` 的 suggestedPool 也未提供直达卡池 chips 跳转。
6. **CyberPalette 命名历史包袱**：`Cyan/Magenta/VioletGlow` 实为朱砂/金箔/石青；文件注释已声明「改名需同步三文件」，长期债务。
7. **Gacha 结果网格非 Lazy**：外层 verticalScroll + 嵌套 Lazy 会炸，改 Column 全量渲染——十连仅 10 项可接受，但若未来单批扩大到 20+ 需重做滚动方案。
8. **Deck 空槽引导 Snackbar** 与 Tower 空槽「跳去组队页」语义分叉，靠调用方区分；组件本身无 slot empty 点击语义。
9. **Home CrashDialog 停留在 Toast** 复制反馈，未迁 LocalFeedback（唯一残留 Toast 路径）。
10. **演示/测试入口**：`GachaScreen(testMode)` 会关掉 CyberHerald 无限动画（便于截图/测试），但五 tab 无统一 debug 开关。
